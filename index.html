Getting started

Tap the editing area and type. Menu contains the controls. Choose a language for syntax colors and automatic indentation. Indent and Unindent work on the current line or selected lines.

Under Buttons, choose Text or Icons. Icons have accessible labels and hover hints. Set Text size from 10 to 54 pt; this changes the document display, not the file contents. Light/Dark changes appearance. Full screen hides the toolbar; Exit full screen restores it.

Search and replace

Menu → Search / Replace opens a panel with Find and Replace fields. Enter the text to find. Next and Previous move between matches; searches wrap around the document. Match case distinguishes capital and lowercase letters. By word matches complete words. Regexp enables regular expressions; leave it off for ordinary searches.

Enter replacement text, then Replace to change the selected match, or Replace all for the document. Undo with Ctrl+Z or ⌘Z if needed. The × button closes the panel. Ctrl+F or ⌘F opens search. Menu → Go to line jumps to a line number.

Select all and copy

Menu → Select all selects the entire document. Reopen Menu and tap Copy to copy the selection to your device clipboard, then paste into another app. To copy only part, select that text first. Copy never removes text. If clipboard access is blocked, a Copy text window lets you select and copy manually.

Optional Vim mode

Menu → Editing → Vim enables Vim key bindings. Standard is the default. Vim is best used with a hardware keyboard. Press i to type (Insert mode), and Esc to return to Normal mode. Switch Editing back to Standard whenever you prefer ordinary editing.

Syntax checking

Menu → Check syntax checks the current document without running it. ATE first detects a recognized filename extension, then scans ambiguous files locally for a likely language. You can override Language in Menu. Detection never renames files; Save preserves extensionless names. Check while typing updates results after a short pause. The footer opens the latest results; tap an issue to jump to its line. An empty list with “check unavailable” does not mean the code is valid.

JavaScript, TypeScript, JSON, YAML, HTML and CSS use bundled offline parsers. TypeScript checking covers syntax only, not types. HTML checking includes inline JavaScript/JSON and CSS; it accepts tags that HTML permits you to omit. CSS checks parsing, not property names or browser support. C uses a bundled basic syntax parser by default on every platform: no compiler download is needed. It checks C structure, but does not resolve headers, expand macros, check types or enforce a particular C standard. Python uses a bundled offline Python 3.13 syntax parser without executing source. SQL checks SQLite syntax without a database. Markdown lint warns about duplicate headings, unclosed code fences and trailing whitespace. Checks are limited to 512K characters and the first 100 issues. Slow checks stop automatically.

For optional deeper checks in the Mac and Windows desktop apps, choose C settings → C checking → Advanced: installed Clang. On Mac, install Apple Command Line Tools. On Windows, choose Get free C compiler in C settings to optionally download LLVM-MinGW (191 MB, 3 GB free space required). Confirm Download and install to begin. ATE verifies the official download checksum, keeps licenses, and checks standard headers before enabling it. Cancel setup stops the installation; Later keeps editing without a compiler. Setup uses your app data folder with no administrator access or PATH changes, and ATE remembers the installed toolchain after restart. You may also choose an existing compiler. Under C settings, select clang if it is not on PATH, choose the C standard, and optionally choose a source folder, additional include directories and preprocessor macros. Paths and macros are entered one per line; macros use NAME or NAME=value. For a file in a subfolder, choose that file’s folder so quoted relative headers resolve correctly. Header files remain on disk; only the open buffer is checked. Manually selected compiler and project folders last for this app session. The optional ATE-managed Windows compiler is detected again after restart. C checking never builds or runs your program. On iPad and the web, About C checks explains the included basic parser and its limits.

iOS document tabs

On iPhone and iPad, New and Open add tabs (up to 12). Tap a filename to switch. A dot marks unsaved changes. Each tab keeps its undo history while the app is running. The × closes one tab; unsaved tabs offer Save, Discard or Cancel. Recovery restores text, filenames, language choices and selection after restarting; undo history starts fresh. Recovery is local, has limited storage and is not a saved file. iOS Save creates a copy through the share sheet; confirm that copy in Files before discarding your work.

Files, drafts and exit

Open imports a plain-text file. On the web, Save file downloads a copy. On iOS, it opens a share sheet: choose Save to Files. On Android and Fire tablets, Save opens the system file manager so you can choose a folder and filename. Cancelling keeps your draft. On Windows and Mac, it opens a native Save dialog; choose a destination and confirm replacement if necessary. Web and iOS saves create a copy. Desktop saves can replace a file you select. Check your Downloads or Files app. The editor displays and saves text; it does not execute code.

A recovery draft is saved in this browser on this device. It is not cloud synchronization. Clearing browser data removes it. Save independent file copies for safekeeping.

Exit offers Keep editing, Save and exit, or Exit without saving. Exit without saving clears the browser draft; existing device files stay intact. Save and exit keeps a recovery draft because the browser cannot verify completion of the download. Closing clears the editor and dismisses its panels and keyboard without showing a closing page. On Windows and Mac, Exit closes the application; the window close button also opens the Exit choices. On iPhone and iPad, use the Home gesture to leave the app.
