Getting started

Tap the editing area and type. Menu contains the controls. Choose a language for syntax colors and automatic indentation. Indent and Unindent work on the current line or selected lines.

Under Buttons, choose Text or Icons. Icons have accessible labels and hover hints. Set Text size from 10 to 54 pt; this changes the document display, not the file contents. Light/Dark changes appearance. Full screen hides the toolbar; Exit full screen restores it.

Search and replace

Menu → Search / Replace opens a panel with Find and Replace fields. Enter the text to find. Next and Previous move between matches; searches wrap around the document. Match case distinguishes capital and lowercase letters. By word matches complete words. Regexp enables regular expressions; leave it off for ordinary searches.

Enter replacement text, then Replace to change the selected match, or Replace all for the document. Undo with Ctrl+Z or ⌘Z if needed. The × button closes the panel. Ctrl+F or ⌘F opens search. Menu → Go to line jumps to a line number.

Select all and copy

Menu → Select all selects the entire document. Reopen Menu and tap Copy to copy the selection to your device clipboard, then paste into another app. To copy only part, select that text first. Copy never removes text. If clipboard access is blocked, a Copy text window lets you select and copy manually.

Optional Vim mode

Menu → Editing → Vim enables Vim key bindings. Standard is the default. Vim is best used with a hardware keyboard. Press i to type (Insert mode), and Esc to return to Normal mode. Switch Editing back to Standard whenever you prefer ordinary editing.

Press Esc before : to start a command line. Press Enter to run the command. Vim’s yank register is separate from your device clipboard; use the Copy button to paste into other apps. This is embedded Vim key binding support, not a terminal or a complete Vim installation. Exit choices still confirm discarding when using :q.

Files, drafts and exit

Open imports a plain-text file. Save file downloads a copy; it does not overwrite the original file. Check your Downloads or Files app. The editor displays and saves text; it does not execute code.

A recovery draft is saved in this browser on this device. It is not cloud synchronization. Clearing browser data removes it. Save independent file copies for safekeeping.

Exit offers Keep editing, Save and exit, or Exit without saving. Exit without saving clears the browser draft; existing device files stay intact. Save and exit keeps a recovery draft because the browser cannot verify completion of the download. After Editor closed appears, close the browser tab yourself.
