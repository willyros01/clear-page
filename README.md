# Clear Page

A simple full-screen text editor with very large adjustable text.

## Run the baseline
Open `index.html` in a browser. No build or dependencies are required.

Use Open to import a text file, Save file to download a copy, A−/A+ to adjust text size, and Full screen to hide the toolbar. Browser fullscreen availability varies by device; the focus layout still works when fullscreen is unavailable.

Draft recovery uses this browser's local storage. Clearing browser data removes the draft. Save a file to keep an independent copy.
